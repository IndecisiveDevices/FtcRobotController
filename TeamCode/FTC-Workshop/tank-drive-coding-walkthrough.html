Mission

Make the robot drive with two sticks

Tank drive is simple: the left joystick controls the left wheels, and the right joystick controls the right wheels. Push both sticks forward and the robot drives forward. Pull one stick back and the robot turns.

You will start in TankDrive_Tutorial_Start.java. By the end, your code will do the same job as TankDrive_Complete.java.

Important: Your file name and class name should match. If you are editing the tutorial file, keep the class line as TankDrive_Tutorial_Start unless a coach tells you to rename it.

What you already have

  • The FTC imports are ready.
  • The robot program is a TeleOp.
  • There is one motor variable started for you.
  • The init() and loop() methods are waiting for code.

Two special FTC methods

init() runs once when the robot is getting ready. We use it to connect code names to real motors.

loop() repeats while the robot is active. We use it to read joysticks and update motor power again and again.

Typing plan

  • Add four motor variables.
  • Connect those variables to the robot motors.
  • Flip the left motors so forward means forward.
  • Read the joysticks and send power to the wheels.
  • Build the code and test carefully.

Connect Code to Motors

First we give each motor a Java name, then we connect it to the robot hardware map.
Page 2 of 5
1

Add the motor variables

Near the top of the class, you already have one motor variable. Add the other three so Java has a name for every drive motor.

private DcMotor frontLeftDrive; private DcMotor frontRightDrive; private DcMotor rearLeftDrive; private DcMotor rearRightDrive;

A variable is a label for something we want to use later. These labels will point to the four drive motors.

Where does this go?

Put these lines inside the class, but above init(). They should line up with the starter line already in your file.

public class TankDrive_Tutorial_Start extends OpMode { private DcMotor frontLeftDrive; ... }
2

Connect the variables in init()

Inside the init() method, type these four lines:

frontLeftDrive = hardwareMap.get(DcMotor.class, "FL"); rearLeftDrive = hardwareMap.get(DcMotor.class, "RL"); frontRightDrive = hardwareMap.get(DcMotor.class, "FR"); rearRightDrive = hardwareMap.get(DcMotor.class, "RR");

hardwareMap.get(DcMotor.class, "FL") asks the FTC robot system to find the DC motor named FL in the robot configuration. Then it stores that motor in frontLeftDrive so our code can use it later.

Name check

The letters inside the quotes must match the robot configuration exactly. "FL" works only if the configured motor name is also FL.

3

Reverse the left side

Add these two lines at the bottom of init(), after the hardware map lines:

frontLeftDrive.setDirection(DcMotorSimple.Direction.REVERSE); rearLeftDrive.setDirection(DcMotorSimple.Direction.REVERSE);

Drive motors on opposite sides of the robot are mounted like mirror images. Reversing the left side helps both sides agree that positive power means driving forward when both sticks move the same way.

Make the Wheels Respond

Now the robot can read joysticks and send power to the motors.
Page 3 of 5

Checkpoint: your init() method should look like this

public void init() { frontLeftDrive = hardwareMap.get(DcMotor.class, "FL"); rearLeftDrive = hardwareMap.get(DcMotor.class, "RL"); frontRightDrive = hardwareMap.get(DcMotor.class, "FR"); rearRightDrive = hardwareMap.get(DcMotor.class, "RR"); frontLeftDrive.setDirection(DcMotorSimple.Direction.REVERSE); rearLeftDrive.setDirection(DcMotorSimple.Direction.REVERSE); }

init() now finds the four drive motors and fixes the left side direction so forward means forward.

4

Read the joysticks in loop()

Inside loop(), add two number variables. These store the left and right joystick power.

double leftPower = -gamepad1.left_stick_y; double rightPower = -gamepad1.right_stick_y;

The minus sign flips the joystick value. FTC gamepads report pushing a stick up as a negative number, but most drivers expect pushing up to mean forward.

Quick joystick picture

Push up
value is about -1
Add minus
power becomes +1

So this line turns "stick up" into "drive forward."

5

Send power to all four motors

The left motors get left joystick power. The right motors get right joystick power.

frontLeftDrive.setPower(leftPower); rearLeftDrive.setPower(leftPower); frontRightDrive.setPower(rightPower); rearRightDrive.setPower(rightPower);

setPower() expects a number between -1.0 and 1.0. Negative power drives backward, positive power drives forward, and numbers closer to zero move more gently.

6

Show power on the Driver Hub

Telemetry prints helpful information while the OpMode runs. Add this at the bottom of loop():

telemetry.addData("Left Power", leftPower); telemetry.addData("Right Power", rightPower);
Step 4 through 6 - Joystick input, motor power, telemetry Left stick controls left wheels. Right stick controls right wheels.

public void loop() { //---------------------------------- // Tank Drive Controls with gamepad1 //---------------------------------- double leftPower = -gamepad1.left_stick_y; double rightPower = -gamepad1.right_stick_y; frontLeftDrive.setPower(leftPower); rearLeftDrive.setPower(leftPower); frontRightDrive.setPower(rightPower); rearRightDrive.setPower(rightPower); telemetry.addData("Left Power", leftPower); telemetry.addData("Right Power", rightPower); }

Before you press Build

  • Every line that is a command ends with a semicolon.
  • Every opening curly bracket { has a matching closing curly bracket }.
  • The motor names inside quotes are exactly "FL", "RL", "FR", and "RR".
  • The left and right joystick lines both have the minus sign.
  • Your code is inside the correct method: setup code in init(), driving code in loop().

Test carefully

After the code builds, put the robot on blocks before driving. Press INIT, then START, and gently move one joystick at a time.

If a side drives backward, ask a coach before changing code. That usually means one motor direction needs attention.
